# VCS Functional Verification

This directory contains the files used for RTL functional verification of the Alarm Clock design using Synopsys VCS.

## Purpose

The objective of this stage is to verify the functional behavior of the RTL before proceeding to logic synthesis and physical implementation.

## Verification Flow

RTL Source
    ↓
Testbench
    ↓
VCS Compilation
    ↓
Simulation
    ↓
DVE Waveform Analysis
    ↓
Functional Verification

## Verification Result

The repository includes the simulation result showing a successful functional verification run and the corresponding DVE waveform.

## Contents

The `vcs/` directory contains the existing VCS files and Verilog source files used by the verification flow.

No additional source files are generated by this README.
